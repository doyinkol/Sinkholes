# Sinkholes
This repository contains all the data and code needed to reproduce the analysis and findings reported in our published project papers as follows:

Paper #1 = "Kolawole O., Sousa R.L., Comuso C., Hussein M. (2026) Sinkhole hazards, infrastructure risk, and remediation: a fifty-year case study in New Jersey, USA. In: Proceedings of the 18th Multidisciplinary Conference on Sinkholes and the Engineering and Environmental Impacts of Karst (Sinkhole 2026). National Cave and Karst Research Institute, Carlsbad, NM. http://doi.org/10.5038/9781967518012.1031".

Paper #2 = "Kolawole O., Sousa R.L., Dahy B. Sinkhole Hazards, Infrastructure Risk, and Remediation in Densely Urbanized Karst and Mine Subsidence Terrain: Fifty-Year Evidence and a Transferable Framework. Under Review - Natural Hazards".
